Archived 2026-09-06, at the user's explicit request: the zero-training SAM + calibration-square classical pipeline for panel detection, panel/lead cropping, and orientation, previously in `repo/research-ecg-digitalization/src/{inference,qa,synthetic}/`. Not deleted outright because most of it was never committed to that repo's git history (`git log --all -- src/synthetic/` returns nothing, and several `src/inference`/`src/qa` files were untracked) -- moving here keeps it recoverable instead of causing silent, permanent loss.

Superseded by the trained-model approach in `repo/research-ecg-digitalization/src/{detection,rectification}/`: a fine-tuned YOLO detector for panel bboxes (step 1) and two rectification approaches, classical grid-angle plus a learned regression head (step 2). See `context/plan.md`'s Pipeline section for current status.

`src/inference/panel_geometry.py` (grid pitch, calibration square, discrete orientation) was NOT archived -- it doesn't use SAM, and the new plan's `src/rectification/rectify_classical.py` actively reuses its `choose_orientation()` rather than reimplementing it.

## What's here

- `src/inference/`: `segment_sheets.py` + `run_sam_panel_segmentation.py` (SAM sheet segmentation, two variants), `detect_panel_anchors.py` (pre-SAM calibration-square anchor approach, superseded by SAM per its own docstring), `panels_from_sheets.py` + `pages_to_panels.py` (panel-finding + orchestrator implementing the `preprocessed/{pages,panels,leds}/` convention the 2026-09-05 plan reset moved away from -- see `context/plan.md`'s "Not carried over from the deleted plan"), `detect_and_digitize_columns.py` (older fused column-finding + digitization stage), `leads_to_signals.py` (Task 4, consumes `panels_from_sheets.py`'s manifest), `run_full_pipeline.py` (end-to-end orchestrator tying the above to the still-active classifier scripts).
- `src/qa/`: scoring and visualization tools scoped to the above pipeline's own output formats (`score_stage1.py`, `rerun_stage1_and_2.py`, `rerun_stage2.py`, `visualize_pipeline.py`, `visualize_stage_a.py`, `visualize_stage_b.py`, `measure_grid_regularity.py`, `score_rotation_ocr.py`, `score_panels_leads.py`).
- `src/synthetic/`: the earlier Phase A/B/C synthetic-ground-truth compositor (`render_panels_from_ptbxl.py`, `compose_synthetic_page.py`, `score_synthetic_pipeline.py`, `tune_calibration_thresholds.py`) -- already marked "deliberately disregarded" in the 2026-09-05 plan reset, in favor of the fresh build in `repo/ecg-synthetic-realistic/`.

Not moved: `run_ecgtizer.py`, `run_paper_ecg.py`, `run_ecg_fm_classifier.py`, `run_physionet2020_classifier.py` -- these are step 3/4 (lead digitization, classification), which `context/plan.md` still treats as solved-enough by existing pretrained/classical tools, unrelated to the panel-detection approach being replaced.

Update 2026-09-06: the coordinate-frame bug noted above (`panels_from_sheets.py`'s panel boxes never mapped back from the SAM-deskewed sheet's local frame into page pixels) was fixed by the datasets session, in flight at the same time this code got archived -- their edit landed before the move, so the fix is already in the copies here: `segment_sheets.py`'s `deskew_crop()` now returns `(crop, matrix)` instead of discarding the perspective matrix, and `panels_from_sheets.py` gained `map_box_to_page()`, composing that matrix with the inverse of the discrete `rotation_deg` rotation. Verified by them against a synthetic page with known ground truth (recovered box within ~1% of true, residual attributed to axis-aligning an already-warped quad, not a transform-math error). Moot for the active pipeline (YOLO detects panels directly on full pages now, so this coordinate problem doesn't arise), but the fix is real and sitting here ready to reuse if a classical SAM baseline is ever wanted again.
